How it works

Point it at any help center that has a sitemap and any ticket queue. This run used Claude's public docs.

  1. Collect tickets from the inbox as they arrive.
  2. Crawl the docs from the site's sitemap into a searchable snapshot.
  3. Group by topic with Claude, by the question the customer needs answered.
  4. Check coverage of each ticket against the closest articles: covered, partial or missing.
  5. Rank the gaps by ticket volume times missing coverage.
  6. Draft the fix for the biggest gap, then re-check every open ticket against it.
